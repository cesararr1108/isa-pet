# Isa Pet – Mockups UX/UI

Maquetas de la tienda (cliente) y del panel administrativo. Abre cualquier `.html` en el navegador o mira las imágenes en `img/`.

| # | Pantalla | Panel |
|---|----------|-------|
| 01 | Inicio de la tienda | Tienda |
| 02 | Carrito de compras | Tienda |
| 03 | Dashboard | Admin |
| 04 | Ingreso de facturas de proveedor | Admin |
| 05 | Facturación de pedidos | Admin |
| 06 | Creación de productos / materiales | Admin |
| 07 | Devoluciones y notas de crédito | Admin |
| 08 | Cajas / POS (arqueo y cierre) | Admin |

`gen.sh` contiene la barra lateral compartida del admin usada para generar las páginas 03–08.
